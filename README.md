# IEC 60909 Short Circuit Calculator

Herramienta desarrollada en Python para el cálculo de corrientes de cortocircuito según IEC 60909.

## Características

- Cálculo de corrientes de cortocircuito.
- Método por unidad (p.u.).
- Uso gratuito.
